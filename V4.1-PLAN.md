# V4.1 — Analysis views and negative-net category wheel

Authorized 12 November 2026. Reference: wireframes/wallet-v4.1-wireframe-r01.html.

- Analysis drop-down switches Calendar, Category Breakdown, and Flow Graph. Default is Calendar. Selection survives recreation.
- Calendar keeps full-month, all-account totals. Detailed range/account controls are shared between the two detailed views and stay independent of calendar navigation.
- User decision supersedes the sketch: the wheel is Net only and includes only negative-net categories. Slices use absolute negative values; the list retains signed amounts. Positive/zero categories are omitted. Transfers remain excluded.
- Flow Graph retains Net/Income/Expenses and its category list. Wheel selection does not change that mode.
- Native Canvas chart; no runtime dependency or database schema change. Category background colors identify slices; signed category list provides accessible values.
