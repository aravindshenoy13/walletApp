# Wallet V4.3.1 implementation plan

This plan refines V4.3; it does not itself authorize implementation.

## Requested changes

1. Put each Analysis Income/Expenses/Net summary in one shared box, styled consistently with the app. Use the compact chart/graph summary font size and spacing for Daily Breakdown too.
2. Remove the box and background around Records date headings; keep day separation subtle and readable.
3. Restore the calendar's thinner grid borders from before V4.3.
4. Brighten category background colors in dark mode while keeping icons readable; retain light-mode colors and saved selections.
5. Replace the boxed Today/month control and arrow with a simple recognizable toggle in the normal app font. Show the month as, for example, “This month · Nov 2026”, without a full date range.
6. Style Delete actions with red icon, text, and outline; Save actions green; Add actions blue. Keep their backgrounds unfilled and ensure colors remain legible in both themes.
7. Use the light-mode transfer icon and amount colors in both light and dark mode.
8. Remove the visible “Built-in” label from category rows and reduce their height and spacing. Preserve category data and editing behavior.

## Implementation and verification

- Start from V4.3, reuse the existing native styles and theme resources, and keep dependencies minimal.
- Preserve summary calculations, the Today/month toggle behavior, category selections, transfer amounts, and the distinction between built-in and custom categories in stored data.
- Review the affected screens in light and dark mode, including compact layouts and accessible touch targets. Run applicable existing checks and build the debug app when implementation is requested.
- Update version metadata and documentation for V4.3.1. Planning alone does not complete the app version.
