# V5.1 — UI design consistency

Authorized scope: D01–D26 in UI-DESIGN-REVIEW.md. Version name 5.1, version code 12.

## Changes and design decisions

- D01–D03: fixed secondary Settings header, full-width divider, 8 dp header gutters, and 4 dp Back icon gaps on generated screens. Options retain 16 dp gutters and scroll independently.
- D04–D06: date headings align to list gutters; only the first heading loses its leading 12 dp margin. Transaction metadata aligns with the title column, with wrapping retained.
- D07–D09: category Edit gets matching icon and horizontal inset while the whole row remains the only action. Picker outlines remain, separated by 4 dp gaps. History lists get 16 dp bottom padding.
- D10–D16: first labels lose redundant leading margins; archived information remains above the category form. Text/date controls use 4 dp label gaps, selectors use 8 dp. Horizontal tiles have 2 dp side margins and 4 dp icon gaps. Export choices use leading alignment, 12 dp content padding, matching labels and 4 dp gaps. Date/time fields use 16 sp and 12 dp horizontal padding.
- D17–D20: Custom range and icon confirmation align left; icon confirmation uses green Save styling. Export, Restore, and Archive have dedicated local line vectors. Archive uses a red outline and its own symbol; its behavior remains archiving.
- D21–D23: both Net totals and all comparable 24 sp balance headlines are bold. Current balance label/value gap is 4 dp.
- D24–D26: calendar cells draw each shared edge once at 1 dp. Graph date labels reserve descent plus 8 dp bottom space, followed by an 8 dp caption gap. Both charts use 75% of content width, bounded to 240–360 dp height, respecting parent constraints.

- Follow-up naming: Analysis choices are Monthly Overview, Category Breakdown, and Flow Graph.

No new dependencies, data migration, transaction logic, or backup-format changes. Room schema remains 3 and backup format remains 2 with format-1 support.
