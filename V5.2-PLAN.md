# V5.2 — Calculator and category management

Version 5.2, code 13. Accepted on 13 November 2026.

- Renamed the product to Wallet Manager.
- Added a shared amount/calculation field with decimal arithmetic, operator precedence, clear, backspace and equals. Final results round to paise using HALF_UP; Save validates a positive amount within the existing storage limits.
- Moved transaction type above account/category, description below date/time, and Save into the header. Preserved existing icons and colors.
- Added category deletion with confirmation: "Deleting this category will make all its records uncategorised". Records retain their amounts and accounts; category references are cleared transactionally.
- Added the Uncategorised selection and included these records in analysis, export and backup/restore.
- Moved Add account and Add category to the bottom to match Add record.

Room schema remains 3; backup format remains 2. Unit tests and debug/release build results are recorded with the archived artifacts. Android tests were compiled, but device execution for these changes has not been performed.
